# 提交附件目录

当前项目尚未放入下一赛题的真实题目、求解代码或结果，因此暂无可提交的支撑材料。

收到赛题并完成问题划分后，应先用 `华为杯_求解规范/tools/init_supporting_materials.py` 创建 `求解/支撑材料清单.json`。每问完成时由 `build_supporting_materials.py` 自动重建本目录中的 `支撑材料/`，并覆盖本文件为包含以下内容的完整目录：

- 每一问完整可运行的源程序、共享模块和实际运行验证记录；
- 赛题官方原始数据之外，自主查阅、整理或爬取并实际用于建模的数据、采集/整理脚本和来源记录；
- 论文正文因篇幅限制未完整展示、但有复核价值的较大篇幅中间结果图表；
- 题面指定的官方答案或结果文件；
- 每个文件的作用、来源、大小和 SHA-256 完整性信息。

最终交付前必须运行 `audit_supporting_materials.py --stage final`。本模板说明不是通过证据，真实构建后的 `readme.md`、`_支撑材料构建清单.json`、`SHA256SUMS.txt` 和 final 审计报告才是验收依据。
