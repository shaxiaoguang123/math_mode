# T05 actual execution validation

The local backend executes explicit argv with the requested interpreter, captures
real stdout/stderr/returncode/duration, enforces timeout, and records honest
isolation capabilities. Every attempt uses a new run directory and immutable
input/code/spec copies. The parent rechecks sources, snapshot hashes and controls,
then validates declared nonempty JSON/CSV outputs before emitting a run manifest.

The executable fixture computes a sum from original synthetic data and a seeded
random draw. Tests compare repeated actual computations, verify the interpreter,
check secret environment exclusion, and rehash produced files. Negative cases
execute raising code, printed PASS without output, nonzero exit after PASS, NaN,
no output with an old output still present, a sleeping process exceeding timeout,
input-snapshot mutation and repaired-but-still-failing retries. Additional checks
reject unsupported memory enforcement, unchanged retries, a fourth attempt,
interrupted-run skipping, stale source, output tampering, rewritten PASS metadata,
wrong/empty structured output and nonfinite/duplicate-column CSV.

Conda `test`, Python 3.12.13, Windows: **93 passed, 1 skipped** for the complete
suite. The existing symlink creation test remains skipped for missing Windows
privilege. Generated-schema drift, compilation and both figure-skill mirrors are
checked independently. Test workspaces/logs are temporary; no private run paths or
fabricated successful run manifests are published. The run-manifest schema example
is generated by the actual runnable fixture during tests.

Limits: local subprocess is not an OS sandbox; process-tree termination is best
effort. No memory/CPU/network isolation is claimed. Python/NumPy seeds do not
guarantee deterministic GPU libraries. XLSX/TXT output schemas need later adapters
and fail closed here. Preflight failures do not create an executed run. A parent
crash leaves an explicit interrupted run for diagnosis; automated recovery/role
authorization follows in T08. The retry bound conservatively caps the entire
unresolved chain at three total attempts; root-cause review belongs upstream.

Run PASS means process/structure integrity, not numerical correctness. G5 needs
the separate T06 validator. The trusted local owner can rewrite files; hashes
cannot authenticate an adversary with the same filesystem privileges. Full V2
release, historical dry run, PR and CI remain pending.
